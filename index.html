1什麼是 BeautifulSoup4？

BeautifulSoup4（簡稱 bs4）是 Python 生態系中最受歡迎的 HTML / XML 解析套件。它能將雜亂的網頁原始碼轉換成易於操作的「文件樹」，讓你用直覺的方式搜尋、讀取與修改網頁內容。

為什麼需要它？動機

當你使用 requests 或 urllib 抓取網頁後，得到的只是一大串 HTML 字串。要從中取出商品名稱、價格、連結等資料，若用正規表達式（regex）硬拆，程式會又長又脆弱。BeautifulSoup 提供高階 API，讓「找標籤、取屬性、抓文字」變得像寫英文一樣簡單。

requests 抓取 HTML→ BeautifulSoup 解析→ 搜尋 / 遍歷→ 取出資料

安裝方式開始

使用 pip 安裝即可，套件名稱是 beautifulsoup4（import 時用 bs4）。

終端機
pip install beautifulsoup4

若你的專案使用 pyproject.toml（如本專案），可加入依賴後執行 pip install -e .：

pyproject.toml
[project]
dependencies = [
    "beautifulsoup4>=4.12",
]
💡
建議同時安裝 lxml 或 html5lib 作為解析器，速度與容錯能力更佳：pip install lxml

快速上手範例Hello World

以下是最基本的用法：解析一段 HTML 並取出標題文字。

Python
from bs4 import BeautifulSoup

html = "
Hello, BeautifulSoup!
"
soup = BeautifulSoup(html, "html.parser")

print(soup.h1)          # 
Hello, BeautifulSoup!

print(soup.h1.text)     # Hello, BeautifulSoup!
print(soup.h1.string)   # Hello, BeautifulSoup!

2基礎物件與解析器

BeautifulSoup 將 HTML 文件轉換成四種核心物件：Tag、NavigableString、BeautifulSoup 與 Comment。理解它們是掌握 bs4 的第一步。

四種核心物件核心

物件說明範例
BeautifulSoup整個文件的代表，也是解析的入口soup
Tag一個 HTML 標籤，可存取屬性與子節點soup.h1
NavigableString標籤內的文字內容soup.h1.string
CommentHTML 註解，是特殊的 NavigableString

解析器比較選擇

解析器速度容錯需安裝建議
html.parser中等普通內建簡單頁面
lxml快佳需安裝一般爬蟲（推薦）
html5lib慢最佳需安裝極度不規範的頁面
xml快—內建解析 XML
⚠️
若未指定解析器，BeautifulSoup 會自動選擇可用的最佳解析器，但建議明確指定以避免警告訊息。

Tag 的屬性操作重點

Tag 物件可以像字典一樣存取屬性，也能用 get() 安全取值。

Python
from bs4 import BeautifulSoup

html = '範例連結'
soup = BeautifulSoup(html, "html.parser")
a = soup.a

print(a["href"])        # https://example.com
print(a.get("class"))   # ['link']
print(a.get("target"))  # None（不存在時回傳 None）
print(a.attrs)          # {'href': 'https://example.com', 'class': ['link']}
https://example.com
['link']
None
{'href': 'https://example.com', 'class': ['link']}
💡
class 屬性會以「列表」回傳，因為 HTML 允許一個元素有多個 class（如 class="a b"）。

讀取本專案的 apple.html實作

本專案根目錄有 apple.html，我們用它來練習。先讀取檔案並建立 soup 物件。

Python
from bs4 import BeautifulSoup

with open("apple.html", encoding="utf-8") as f:
    soup = BeautifulSoup(f, "html.parser")

print(soup.title)            # APPLE / select your next
print(soup.title.string)     # APPLE / select your next
print(soup.h1.string)        # 選一台，開始下一幕。
print(len(soup.find_all("article")))  # 18 個商品
