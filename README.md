# weather01.py - 臺中市天氣爬蟲

這是一個使用 Python 撰寫的網路爬蟲程式，用於定時抓取**中央氣象署（CWA）** 的**臺中市未來 36 小時天氣預報**，並將資料儲存成 CSV 檔。

## 功能特色

- 🌤️ 抓取臺中市未來 36 小時的溫度與降雨機率預報
- ⏱️ 每 5 分鐘自動抓取一次，直到設定的停止時間
- 📄 自動將資料以 CSV 格式儲存（使用 UTF-8 with BOM 編碼，方便 Excel 直接開啟）
- 🛡️ 內建逾時處理與錯誤處理，避免程式因網路問題中斷

## 使用方式

### 安裝相依套件

```bash
pip install requests
```

### 執行程式

```bash
python weather01.py
```

## 輸出檔案

程式會在同目錄下產生 `weather01.csv`，欄位說明如下：

| 欄位 | 說明 |
|------|------|
| 抓取時間 | 執行抓取的時間 |
| 預報時段 | 預報的起訖時間 |
| 低溫(°C) | 該時段最低溫 |
| 高溫(°C) | 該時段最高溫 |
| 降雨機率(%) | 該時段降雨機率 |

## 程式碼說明

- **`fetch_page()`**：向中央氣象署發送請求，並用正規表達式解析出臺中市的溫度與降雨資料。
- **`save_to_csv(records)`**：將抓取到的資料寫入 CSV 檔，若檔案不存在會自動建立並寫入表頭。
- **`main()`**：主程式迴圈，每 5 分鐘抓取一次，直到設定的停止時間（`STOP_DATETIME`）為止。

## 注意事項

- 程式預設抓取到 `2026-08-21 16:00` 為止，可自行修改 `STOP_DATETIME` 變數調整停止時間。
- 請遵守中央氣象署的網站使用規範，避免過度頻繁的請求。
